## 修复与证据

1. **参数接口恢复能力。** node/edge 启用 Pi 的 `constrainedSampling: json_schema / prefer`，使支持 strict 的 provider 能用 null 表示可选参数；Pi 在本地验证前将其恢复为省略。支持批量输入附带完全中性的单条占位（空字符串、false）。非空 name/task/from/to/relation、true delete/feedback 等竞争字段仍原子拒绝，不能静默丢掉真实编辑。没有放松 Compiler 结构检查，也没有改写任务内容。
2. **工具环境。** dedicated Grapher agent 目录原来没有 bin，而已有 `~/.pi/agent/bin/rg`、`fd`。启动配置现在只复用这两个已存在且可执行的 Pi 管理工具，建立单独符号链接，不覆盖已有工具、不下载、不引入整个上游目录的插件或设置。Pi 本身会把 dedicated bin 加入 shell PATH；本机复用后的 rg --version 已验证。若上游没有工具，仍允许缺失，不将启动变成网络安装流程。
3. **分析口径。** trajectory 脚本增加 firstSuccessfulGraphMutationMs、最长连续图拒绝、诊断计数和明确的 processSuccess。旧 firstGraphMutationMs 保留兼容，但注明是第一次尝试。没有把成功退出伪装成图成功。

确定性回放使用原记录前三次 node 调用原样经过 Pi 参数验证和真实 Compiler：结果从旧行为的 `[false,false,false]` 变为 **`[false,false,true]`**，第三次成功保存原来的 6 节点任务文本。此证据只证明工具可恢复，不代表无边候选已经是正确计划。

## 仍存在的问题与优先级

- **P1：完成条件与人工等待缺失。** 需要系统级结构化的成功证据和人工交接状态，区分“材料交付”“等待账号/用户行动”“真实结果达成”；当前靠 task 文本和最后一条自然语言不足以校验收益类目标。
- **P1：候选策略缺乏用户条件。** 对用户资源、时限、地点和渠道的未知，应有可记录的澄清/决策输入，使编译图明确哪些步骤已经具备执行条件。此次没有用 prompt 强制指定另一种赚钱方式。
- **P2：互斥工具模式仍有摩擦。** 新样本仍先失败两次，实质冲突继续被拒绝。后续可以评估单一批量 wire schema 或独立单条/批量工具，但涉及接口迁移与描述同步，不在此次以容错方式猜测用户编辑。
- **P2：自然语言完成声明不可靠。** 宿主最终编译已正确拦截空图；分析脚本现在明确区分进程与图结果，但尚没有对“节点任务是否真正满足原目标”的独立语义完成门槛。
- **P2：预算仍主要耗在模型往返。** 不宜只缩短 bash 超时或把所有工具失败视为模型无能；可进一步度量无状态进展的重复图拒绝，并研究有证据的恢复或提前结束策略。此次没有引入按错误次数机械中止正常探索的规则。
- **P3：工具分发仍依赖已有安装。** 管理工具复用解决本机配置隔离带来的缺失；未实现无工具环境的离线分发，符号链接目标被删除后也会失效。

## 后续优化：唯一数组入口

用户确认保留批量、去掉单双两种调用入口后，`node` 只接受必填非空 `nodes` 数组，`edge` 只接受必填非空 `edges` 数组。一个操作就是一个元素。旧顶层字段（包括空字符串/false 占位）现在由 schema 拒绝，之前的占位兼容分支已经删除。schema 保留 strict/nullable 支持，只有元素内部的可选字段需要表达缺省。

新增规则：每批节点名、每批有向边的 `(from,to)` 不可重复。相同编辑重复、删除后重建、同方向的 dependency/feedback 编辑均整批拒绝。诊断 `duplicate-target` 包含零起始数组路径、首次出现的位置和目标；校验发生在图修改及 Compiler 调用之前。不同方向是不同目标，所以删除 A→B、新增 B→A 仍可同批原子提交，正常批次只编译一次。

迁移只按接口变化更新两个 tool description 中的入参形式、唯一性说明，以及保留下来的 name 字段约束；系统和角色提示词未变。当前契约见 [planning-inspection.md](../backend/resources/planning-inspection.md)。已有图文件格式不变，旧日志和候选不改写；旧的单条调用格式不再支持。

外置 benchmark 的边界校验、测试和文档同步为 `planner-workspace-tools-v11-array-only`，planning host 同步声明此版本。它不再将 v10 的历史输入当成当前接口证据。外置目录不在本仓库 Git diff 中，修改副本保留于此次证据的 `harness-changes/`。
