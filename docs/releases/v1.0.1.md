# Grapher v1.0.1

> **Status:** archived
> **Scope:** Release-specific record, not the current baseline or setup contract. For current behavior, see [Installation](../guides/installation.md) and [Pi integration](../development/pi-integration.md).

The first patch release of the 1.0 series: workbench reliability fixes and clearer Planner contracts on top of v1.0.0, packaged the same way — relocatable archives for Linux x64, Windows x64, macOS Apple Silicon (ARM64), and macOS Intel (x64), with no Rust toolchain or npm installation needed to run an archive.

See [CHANGELOG.md](https://github.com/zhexusun10/grapher/blob/v1.0.1/CHANGELOG.md) for the complete change list.

## Highlights

- **`completed` replaces `done` as the node execution status** across the runtime, snapshot events, planner prompts and UI. Historical checkpoints are normalized in memory on load while stored events stay unchanged, so existing Runs keep rendering and completing correctly.
- **Clearer Planner contracts:** the planner prompt and `node`/`edge` tool descriptions now state that Executor context is isolated (other nodes' names, tasks and file responsibilities are not automatically included — supply necessary context in the task or inherited project files) and that dependency handoff carries project-file results; feedback edges also pass the source's completed project-file state to the reworked node.
- **Conversation transcript pipeline rework:** a dedicated incremental transcript parser service replaces the ad-hoc rendering logic in the virtualized transcript; conversation-history auto-fill is bounded per burst by bytes and resumes on upward wheel, touch or keyboard gestures instead of loading unbounded history; the planner shows a live elapsed duration while planning; and expanding or collapsing the workspace details panel scrolls only the additional required height.
- **Workbench fixes:** overview node chips sort by execution order instead of alphabetically, the prompt placeholder no longer clips when the node name is long, and prompt-box controls stay in normal flow so mode-selector motion and button hover transitions work during resize.

## Installation

Install **Node.js 22.19+** and **Git** on your host, then download the archive matching your platform and CPU and verify its `.sha256` checksum. Extract the **entire archive**, retaining its directory structure and hidden files.

- **Windows:** double-click `start.bat`. The first launch may show a SmartScreen prompt for the unsigned binary — choose **More info** → **Run anyway**.
- **macOS:** run `./start.sh` inside the extracted directory (`arm64` for Apple Silicon, `x64` for Intel; `uname -m` shows which).
- **Linux:** run `./start.sh`. Graph isolation requires bubblewrap and permitted user/mount/PID namespaces.

Open **http://127.0.0.1:1421**, configure a project, authenticate a provider in Settings, and select a model. Windows provides process isolation, **not a filesystem sandbox**; task-specific tools and dependencies still need to be installed on the host or in the project.
