# Grapher v0.1.0-alpha.2

> **Status:** archived
> **Scope:** Release-specific record, not the current baseline or setup contract. For current behavior, see [Installation](../guides/installation.md) and [Pi integration](../development/pi-integration.md).

An alpha preview of the local Pi coding-agent workbench, with relocatable packages for Linux x64, Windows x64, macOS Apple Silicon (ARM64), and macOS Intel (x64).

## Highlights

- Upgrade the pinned Pi engine to 1.0.1 and refresh the checksummed model catalog.
- Bundle pi-trim 0.2.0 and pi-continuity 0.1.0, with extension discovery and settings in the workbench.
- Improve graph task cards, planner state handling, compiler feedback, and graph display when switching conversations.
- Fix thinking/COT transcript rendering and improve frontend/backend data exchange and caching.
- Preserve credentials and project trust restrictions when merging global, Grapher, and project MCP configurations.
- Improve Windows repository-binding compatibility and Linux runtime checks.
- Use an audited Pi core dependency profile, excluding vulnerable optional-example and shelljs dependency chains.

## Packaging fixes

- Include runtime scripts, both bundled extension packages, the ESM package boundary, and independent Pi Git metadata.
- Locate the runtime, frontend, configuration, and data relative to the installed executable instead of the CI checkout.
- Use Pi's audited source loader for Provider/Auth, without downloading tsx on startup.
- Build separate, correctly labelled macOS ARM64 and Intel x64 packages.
- Smoke-test the actual extracted archives in relocated paths with spaces and Unicode: Pi CLI/IPC, local-provider trim/continuity contracts, Graph runtime preparation, provider discovery, extensions, backend startup, and frontend serving.

## Installation

Install **Node.js 22.19+** and **Git** on your host, then download the archive matching your platform and CPU. A Rust toolchain and npm installation are not needed to start these packages.

Verify the SHA256 checksum and extract the **entire archive**, retaining its directory structure and hidden files.

- **Linux/macOS:** enter the extracted directory and run `./start.sh`.
- **Windows:** enter the extracted directory and run `start.bat`. Install Git for Windows Bash.

Open **http://127.0.0.1:1421**, configure a project, authenticate a provider in Settings, and select a model.

Linux Graph isolation requires bubblewrap and permitted user/mount/PID namespaces. macOS Graph uses sandbox-exec/Seatbelt; macOS packages are built and smoke-tested on macOS 15. Windows provides process isolation, **not a filesystem sandbox**. Task-specific tools and dependencies still need to be installed on the host/project.

## Validation and safety

Release CI checks extracted packages on all four OS/architecture targets before uploading assets. Linux/Windows native, planner-source, and dependency-audit checks cover the source commit. Local scripted-provider tests do not constitute independently reviewed live-provider capability or benchmark results.

This is alpha software: no stable API or persisted-data compatibility guarantee. Back up projects and runtime data before upgrades. Use trusted projects, tools, and extensions. Planning can modify projects before approval; rejection is not rollback. Provider calls may incur costs. Keep the local API on loopback.
