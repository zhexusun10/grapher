# Atlas workspace
Small TypeScript service with a browser client and Python SDK.
Source locations: server/users.ts, web/users.ts, src/normalize.ts, src/importer.ts, src/settings.ts.
Client SDKs live in clients/typescript/client.ts and clients/python/client.py.
Contracts live in contracts/. Integration tests live in tests/. Audits are written under reports/.
No generated files are committed. Keep existing public behavior unless the user requests a change.
