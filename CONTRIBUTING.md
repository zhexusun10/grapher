# Contributing

See the [development guide](docs/development/contributing.md) for setup, design rules, testing, and documentation policy.

- Use the [issue templates](https://github.com/zhexusun10/grapher/issues/new/choose) for bugs and feature proposals.
- Keep changes focused and include relevant tests and known limitations.
- Redact credentials, private code, prompts, and local paths before sharing logs.
- Report vulnerabilities privately using the [security policy](SECURITY.md), not a public issue.
